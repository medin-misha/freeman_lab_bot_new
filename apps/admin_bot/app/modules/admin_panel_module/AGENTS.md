# Admin Panel Module Agent Context

## Purpose

`app/modules/admin_panel_module` отвечает за предоставление точки входа в WebApp админ-панели для доверенных администраторов.

Оно отвечает за:
- обработку команды `/admin`
- валидацию пользователя в списке `ADMINS_CHAT_IDS`
- отправку inline-кнопки открытия WebApp `admin-mini-app`

## What Belongs Here

- Хендлер команды `/admin`
- Получение сообщений из ресурсного файла `messages.json`
- Inline-клавиатуры для открытия WebApp
- Модульный конфигуратор, считывающий `admin_url`

## What Does Not Belong Here

- Другие диагностические или аналитические хендлеры
- Логика взаимодействия с БД или API бэкенда (это вынесено в Mini App или другие специализированные слои)

## Design Rules

- Строго следовать бесконфликтной структуре ресурсного файла `messages.json`
- Не хардкодить текстовые блоки в коде `handlers.py`
- Переиспользовать центральную конфигурацию приложения `ADMIN_URL`
- Разделять конфигурационный слой, клавиатуру и логику команд
