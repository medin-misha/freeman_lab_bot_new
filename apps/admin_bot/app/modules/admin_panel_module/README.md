# Admin Panel Module

`app/modules/admin_panel_module` отвечает за предоставление доступа к Telegram Mini App админ-панели для доверенных администраторов.

## Responsibility

Модуль:
- Обрабатывает команду `/admin` для администраторов.
- Проверяет наличие прав доступа пользователя на основе `ADMINS_CHAT_IDS`.
- Отображает приветственное сообщение и отправляет inline-клавиатуру для открытия WebApp по адресу `ADMIN_URL`.
- Локализован с использованием внешнего ресурсного файла `messages.json` согласно общесистемной спецификации.

## File Map

- `handlers.py` — обработчик команды `/admin`.
- `keyboards.py` — клавиатура запуска Mini App.
- `messages.py` — утилита кэширования и чтения ресурсного файла.
- `messages.json` — ресурсный файл с текстовыми шаблонами сообщений.
- `config.py` — локальные конфигурации модуля, считывающие `admin_url`.
