# Analysis Module

`app/modules/analysis_module` отвечает за Telegram-сценарий записи на разбор.

## Purpose

Когда пользователь нажимает кнопку `Записаться на Разбор`, модуль:

- отправляет вводное сообщение о формате разбора
- показывает inline-кнопки `Публичный разбор` и `Приватный разбор`
- по выбору формата отправляет отдельное сообщение с описанием
- прикладывает URL-кнопку анкеты и callback-кнопку подтверждения заполнения
- после подтверждения анкеты переводит пользователя на шаг записи в расписание
- после подтверждения расписания создаёт запись на разбор в backend

## Responsibility

Модуль владеет только UI-сценарием внутри Telegram:

- вход по reply-кнопке из главного меню
- inline-навигация по двум форматам разбора
- переходом к нужному листу расписания для публичного или приватного разбора
- отправкой `POST /api/analysis-registrations` после подтверждения записи

## Boundaries

- здесь не должно быть сложной backend-логики кроме создания записи на разбор
- здесь не должно быть логики дальнейшего сопровождения после создания записи
- тексты и inline-кнопки должны оставаться изолированы внутри модуля

## File Map

- `handlers.py`
  Пользовательские хендлеры и callback-ветки сценария.
- `service.py`
  Backend orchestration для создания записи на разбор.
- `keyboards.py`
  Inline-клавиатуры выбора формата и перехода к анкетам.
- `messages.py` и `messages.json`
  Пользовательские тексты модуля.
